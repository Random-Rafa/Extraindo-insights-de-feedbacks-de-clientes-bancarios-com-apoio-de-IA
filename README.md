# Extraindo-insights-de-feedbacks-de-clientes-bancarios-com-apoio-de-IA
prompt de extração insights de feedbacks

Desafio proposto pela DIO, na personalização de um modelo de prompt para melhor extração de dados.
neste desafio analisei mais modelos de prompt, que em conjunto se tornaram um prompt robusto e com maior precisão em sua respota.

## Prompt

Quero que a IA analise essa base de feedbacks e comentários para identificar critícas negativas frequentes sobre nosso sistema.

O resultado será usado por devs para apoiar a melhoria do software.

A entrega deve conter um resumo técnico, uma tabela com os temas mais abordados e com número de reclamações e comentários de maior relevâcia.

O resultado será considerado bom se organizado, com base nos comentários de maior relevância ou quantidade e com pontos de melhoria acertivos.


Contexto: Estou trabalhando com feedbacks de clientes bancários relacionados ao aplicativo mobile.

Dados disponíveis: A base contém cómentarios, avaliação de satisfação de 1 a 5 estrelas, textos críticos, data e hora da públicação e reações positivas (concordando com o comentário) e negativas (discordando do comentário).

Critérios de análise: A IA deve classificar os feedbacks por úrgência (pequena, média, grande), pensando no impacto que pode acarretar para empresa e na experiêcnia para os clientes, pensando especialmente nas heurísticas de usabilidade.

Cuidados e restrições:

Use apenas os dados fornecidos.
Não invente números, causas ou conclusões.
Não exponha dados pessoais ou sensíveis.
Se houver informação insuficiente, indique a limitação.
Use linguagem objetiva e técnica.


Atue como analista de dados.

Sua tarefa é analisar comentários avaliativos sobre o sistema do aplicativo para identificar melhorias a se fazer.

Contexto: é analisar os comentários de feedbacks negativos dos úsuarios e agrupalos de forma clara e coesa, procurando melhorias para usablidade do app.

Dados disponíveis:  A base contém cómentarios, avaliação de satisfação de 1 a 5 estrelas, textos críticos, data e hora da públicação e reações positivas (concordando com o comentário) e negativas (discordando do comentário).


Instruções de análise:

Classifique os feedbacks por pequena, média e grande úrgência.
Identifique os principais padrões, problemas, elogios e oportunidades.
Aponte evidências nos dados fornecidos.
Sugira ações práticas para devs.
Formato da resposta: A entrega deve conter um resumo técnico, uma tabela com os temas mais abordados e com número de reclamações, comentários de maior relevâcia e pontos de melhoria.

Restrições:

Use apenas os dados fornecidos.
Não invente números, causas ou conclusões.
Não exponha dados pessoais ou sensíveis.
Informe limitações quando os dados não forem suficientes.
Use linguagem objetiva e técnica.
